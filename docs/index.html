01 / INSTALL

Start with one task.

Node.js 22 or newer, plus the destination CLI and its own working login. The runtime installs from GitHub.

Release & download ↗
TERMINAL 
npm install -g github:niharnm/grok-bridge#v0.1.0-alpha.1

Then run grok-bridge doctor to check installed executables.

Grok Bot access also requires the community grok-bot-cli@0.2.3. Its private gateway is experimental.

03 / BEFORE YOU RUN

Keep the task explicit.

Choose the computer.

A Bot’s cloud terminal and your laptop are separate. Reverse handoffs need approved execution where the repository and authenticated CLI exist.

Check the result.

A submission receipt means submitted. Waiting requires a correlated final response. A timeout stops local waiting, without cancelling the cloud Bot.

Read the permissions.

Native policies differ. Cursor work uses force within its sandbox; Antigravity review is plan guidance. Review the destination’s controls before allowing edits.
